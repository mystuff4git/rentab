# Скриншоты v1.0 и GIF

Кадры для [README](../../../README.md): GIF «демо-фирма → смета → КП» и экраны
приложения. Решения — [ADR 0010](../../adr/0010-phase8-release.md).

| Файл | Что делает |
|---|---|
| [`shots.js`](shots.js) | Playwright: сценарий посетителя, скриншоты и кадры GIF с `manifest.json` |
| [`make_gif.py`](make_gif.py) | Pillow: GIF из кадров (ширина 960 px, одна палитра, метки кликов, страница КП) |
| [`cloud_check.js`](cloud_check.js) | Playwright: проверка приватности и работы задеплоенного демо |

Сценарий `shots.js` проверяет по пути: дисклеймер на главной, скачивание КП в
PDF и DOCX и сметы XLSX, отсутствие горизонтальной прокрутки на экране 420 px.

**Как снимались.** Приложение работало в Docker-образе из `Dockerfile` с
файловой системой только для чтения (`--read-only`, `/tmp` в памяти) и
аудит-хуком записи на диск (`tests/server_audit/sitecustomize.py`). За все
прогоны `shots.js` и `cloud_check.js` — 27 записей, все во временном каталоге
(openpyxl собирает XLSX и сразу удаляет файлы), вне его — ни одной, оставшихся
файлов нет.
