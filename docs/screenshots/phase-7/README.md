# Скриншоты фазы 7: экспорт

Сценарий `shots.js` снимает экраны и проверяет в браузере (Playwright, Chromium), что:

- реквизиты и логотип демо-фирмы на месте; логотип удаляется и загружается
  снова (настоящая загрузка файла через браузер);
- условия КП и описание этапа у каждого проекта свои и переживают
  переключение проектов и смену шага;
- кнопки «КП (PDF)», «КП (DOCX)» и «Смета (XLSX)» отдают файлы с правильной
  сигнатурой и именем (файлы собираются по нажатию);
- на экране 420 px нет горизонтальной прокрутки.

Сервер для прогона запускался с аудит-хуком записи на диск
(`tests/app/write_guard.py` через `sitecustomize`): за весь сценарий —
9 записей, все во временном каталоге (openpyxl собирает XLSX), вне его — ни
одной, оставшихся файлов нет.
