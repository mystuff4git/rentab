# ADR 0010. Фаза 8: релиз v1.0.0 — README, Docker, Streamlit Community Cloud

- Статус: принято
- Дата: 2026-10-26
- Фаза: 8

## Контекст

К фазе 8 закрыты фазы 0–7: ядро, методология, ставки 2026 года, приватность,
аналитика, интерфейс и экспорт. Для релиза не хватало README с GIF и
скриншотами, публичного демо, Dockerfile, версии 1.0.0 и сверки с Definition
of Done. Демо v0.3 на `rentab.streamlit.app` собрано из другого репозитория и
по-прежнему пишет профиль фирмы на диск сервера (L-10).

Решения согласованы с автором до реализации — все по рекомендациям:

- README: RU + краткий EN; открытые вопросы — разделом «Что требует проверки»;
- GIF: Playwright + Pillow;
- Streamlit Cloud: `app/requirements.txt` из `uv export`, Python 3.13, поддомен
  `rentab` (приложение v0.3 автор переименовывает или удаляет), превью из ветки
  PR до мержа;
- дисклеймер говорит о статистике Streamlit, если сервер её включил;
- Docker: `python:3.13-slim`, uv, непривилегированный пользователь, только
  чтение, healthcheck, `compose.yaml`, проверка в CI;
- версия 1.0.0 и подпись версии на главной; смета XLSX без НДС — «Без НДС».

## Решение

### README

- Что это и что умеет, GIF, скриншоты (таблица миниатюр), быстрый старт
  (демо, uv, Docker, ядро как библиотека — фрагмент проверен на демо-фирме).
- «Методология»: ключевые формулы блоком кода в записи раздела 1
  `methodology.md` (упрощённо, со ссылкой на полный текст). LaTeX не
  используется: его нет в документах, а блок кода читается везде.
- «Приватность», «Ограничения и дисклеймер» (needs_review, «нужна проверка
  юристом», налог проекта — аппроксимация, короткий список ограничений со
  ссылкой на ROADMAP), «Что требует проверки» — два открытых вопроса ROADMAP
  и как помочь (issue или PR с первоисточником).
- English — один раздел: что это, возможности, как попробовать, приватность,
  дисклеймер.
- Числа реестра (33 из 82 записей с `needs_review`, 8 — к юристу) — из
  `rates_verification.md` версии 1.0; при изменении реестра README правят
  вместе с ним.

### GIF и скриншоты (`docs/screenshots/v1.0/`)

- `shots.js` (Playwright, Node) проходит приложение как посетитель: главная,
  демо-фирма, команда, проект «Регистрация товарного знака», смета, подсказка
  с формулой NNE, структура выручки и светофор, торнадо, документы. Снимает
  скриншоты для README и кадры GIF; для каждого кадра пишет в
  `manifest.json` длительность показа и точку следующего клика. По пути
  проверяет дисклеймер, скачивание КП (PDF, DOCX) и сметы (XLSX), отсутствие
  горизонтальной прокрутки на экране 420 px.
- `make_gif.py` (Pillow — зависимость ядра; ffmpeg и системные пакеты не
  нужны): ширина 960 px, одна палитра на 128 цветов по всем кадрам, без
  дизеринга — текст чёткий, кадры не мерцают, Pillow хранит у кадра только
  изменившуюся область. Клик отмечен полым бордовым кольцом со светлой
  обводкой (видно и на бордовой кнопке). Последний кадр — верх первой страницы
  КП (`docs/examples`, отрисовка PDF). Итог: 12 кадров, 29 с, 0,5 МБ.
- Видео Playwright + ffmpeg отклонено: файл в 3–4 раза тяжелее, палитра рябит.

### Streamlit Community Cloud

- **Файл зависимостей — `app/requirements.txt`.** Cloud ищет файл
  зависимостей сначала рядом с точкой входа, потом в корне, и в каждом месте
  берёт первый из `uv.lock`, `Pipfile`, `environment.yml`, `requirements.txt`,
  `pyproject.toml` (последний — как Poetry). Как Cloud ставит `uv.lock` и
  какие группы берёт, не описано; корневой `uv.lock` по умолчанию тянет и
  dev-группы. Файл в `app/` важнее корневого `uv.lock`.
- Файл генерирует `uv export --frozen --no-default-groups --group app
  --no-hashes --no-editable -o app/requirements.txt`: ядро и группа `app`,
  точные версии, первая строка `.` — сам Rentab. Рабочая папка Cloud — корень
  репозитория; uv и pip читают `.` в `app/requirements.txt` относительно
  рабочей папки (проверено). Без хешей: pip в режиме хешей не ставит проект из
  папки.
- `tests/app/test_deploy.py` сверяет файл с `uv export` (в CI без uv — ошибка)
  и проверяет, что dev-пакетов в нём нет.
- **Python 3.13** выбирается в «Advanced settings» при деплое (по умолчанию
  Cloud ставит 3.12); это версия ячейки CI с LibreOffice и Docker-образа.
- `.streamlit/config.toml` в корне работает на Cloud как есть; `packages.txt`
  не нужен (ADR 0009). Cloud поверх него задаёт `client.showErrorDetails =
  false`, `runner.fastReruns`, `server.runOnSave`,
  `server.enableXsrfProtection = true` и **`browser.gatherUsageStats = true`**.
- **Дисклеймер.** Если `browser.gatherUsageStats` включён (на Cloud — всегда),
  главная добавляет: «На этом сервере включена анонимная статистика
  использования Streamlit: браузер сообщает, какие элементы страницы работают,
  но не введённые в них значения (так Streamlit описывает свою статистику).
  Для полной приватности запустите Rentab у себя — через uv или Docker». Про
  «без введённых значений» — со слов Streamlit (ответ сотрудника на форуме),
  поэтому со ссылкой на них.
- **Проверка «как на Cloud».** Cloud построен на Debian 11. В
  `python:3.13-slim-bullseye` (Debian 11.11, Python 3.13.6) копия репозитория,
  `uv pip install -r app/requirements.txt` из корня и
  `python -m tests.app.deploy_smoke`: страницы с демо-фирмой открываются без
  ошибок, все девять документов побайтно совпадают с `docs/examples/`.
- **Роли.** Код и проверки — в PR. Деплой — автор в интерфейсе
  share.streamlit.io: репозиторий `mystuff4git/rentab`, ветка, Main file
  `app/Home.py`, App URL, Python 3.13, без secrets. Сначала превью из ветки PR
  на временном поддомене, после мержа — `main` на `rentab`.

### Docker

- `Dockerfile`, две стадии на `python:3.13-slim-trixie`:
  - сборка: uv 0.11.32 из `ghcr.io/astral-sh/uv`, `uv sync --locked
    --no-default-groups --group app --no-editable` в `/opt/rentab`; сначала
    зависимости (слой живёт, пока не изменился `uv.lock`), потом Rentab
    колесом; байткод компилируется при сборке;
  - образ: окружение, `app/` и `.streamlit/config.toml`; ни uv, ни исходников
    ядра, ни тестов, ни `legacy`;
  - пользователь `rentab` (uid и gid 10001) без домашнего каталога, файлы
    принадлежат root;
  - `PYTHONDONTWRITEBYTECODE`, файловый наблюдатель Streamlit выключен;
  - `STREAMLIT_BROWSER_SERVER_ADDRESS=localhost`: иначе Streamlit в режиме
    headless при старте спрашивает свой внешний IP у checkip.amazonaws.com —
    только ради строки «External URL». Запросы со своего источника Streamlit
    разрешает всегда, так что открыть приложение по адресу хоста это не мешает;
  - `HEALTHCHECK` — `/_stcore/health` через `python -c urllib` (curl в slim
    нет), с `--start-interval=2s`: контейнер здоров через ~6 с.
- Только чтение — флаг запуска, а не свойство образа: `compose.yaml`
  (`read_only`, `/tmp` в памяти на 64 МБ, `cap_drop: ALL`,
  `no-new-privileges`, порт только на 127.0.0.1) и команда `docker run` в
  README и шапке Dockerfile. `/tmp` нужен openpyxl: он собирает XLSX через
  временные файлы и сразу их удаляет.
- Необязательный секрет `ca`: за прокси с TLS-инспекцией (корпоративная сеть)
  его корневой сертификат передаётся `--secret id=ca,src=…` и в образ не
  попадает.
- Размер: окружение 553 МБ (из них pyarrow — зависимость Streamlit — 170 МБ),
  файловая система образа ≈ 680 МБ.
- **CI, job `docker`:** `docker compose config`, сборка; пользователь 10001 и
  отсутствие pytest в образе; `tests/app/deploy_smoke.py` в контейнере только
  для чтения без сети (страницы с демо-фирмой, документы побайтно равны
  `docs/examples/`, аудит-хук записи); сервер — healthcheck, `/_stcore/health`,
  главная и шрифт из `app/static`; лог сервера без предупреждений и ошибок.
  Сборка — простым `docker build` без кэша GitHub Actions: сторонние actions с
  версиями не нужны, сборка занимает около минуты.

### Аудит записи на настоящем сервере

- `tests/server_audit/sitecustomize.py`: тот же аудит-хук, что в тестах
  приватности (`tests/app/write_guard.py`), для процесса `streamlit run`;
  итог — в stderr при выходе (`docker stop`, Ctrl+C).
- Прогон: образ с `--read-only`, `/tmp` в памяти, хук через `PYTHONPATH`;
  против него — `shots.js` и `cloud_check.js` целиком (загрузка демо-фирмы,
  все шаги, скачивание КП и сметы, вторая сессия, перезагрузка). Итог:
  27 записей, все во временном каталоге (openpyxl), вне его — ни одной,
  оставшихся файлов нет; контейнер завершился с кодом 0.

### Проверка задеплоенного демо (`cloud_check.js`)

Снаружи, как посетитель: дисклеймер и на Cloud — оговорка о статистике;
версия внизу главной; демо-фирма и NNE слайда 3 (225 500 ₽); скачивание КП и
сметы, встроенные шрифты в PDF; изоляция сессий (новая сессия и перезагрузка
видят пустую фирму); список хостов, к которым обращается браузер (шрифтов со
сторонних серверов нет). Запись на диск внутри контейнера Cloud снаружи не
видна — её доказывают тот же коммит и те же версии в Docker с аудит-хуком и
проверка «как на Cloud».

Результат на превью — в разделе «Definition of Done» ROADMAP.

### Версия 1.0.0

- `rentab_core.__version__ = "1.0.0"` — единственный источник: его читают
  hatch, поле `app_version` файла профиля и подпись на главной («Rentab 1.0.0
  · исходный код (MIT) · …»). В `uv.lock` версия проекта не записывается.
- `pyproject.toml`: «Development Status :: 5 - Production/Stable», ссылки на
  демо, методологию и CHANGELOG.
- CHANGELOG: раздел `[1.0.0]` — «Главное» для пользователя и прежние
  разделы фаз; пустой `[Unreleased]`.
- Тег `v1.0.0` — аннотированный, на мерж-коммите в `main`, после мержа PR и ок
  автора. GitHub Release создаёт автор по тегу; текст — из CHANGELOG.

### Смета XLSX: «Без НДС»

`xlsx.NO_VAT_NOTE = offer.NO_VAT`: смета и КП называют отсутствие НДС
одинаково. Снимки `snapshots/core/export` (`billing`,
`billing_no_firm_no_client`, `fixed`) изменились одной строкой — текст
«НДС не облагается.» → «Без НДС»; цифры, мост «было/стало» и снимки v0.3 не
тронуты, примеры `docs/examples` (НДС 5%) не изменились.

## Последствия

- Цифры смет не изменились: снимки ядра (кроме текста трёх снимков XLSX),
  мост и golden-тесты прошли без изменений.
- После `uv lock` нужно перегенерировать `app/requirements.txt` — иначе упадёт
  `test_deploy.py` (команда — в CLAUDE.md и в шапке файла).
- На публичном демо Streamlit собирает анонимную статистику, и данные во
  время сессии обрабатываются на серверах Streamlit Community Cloud за
  пределами России и Казахстана. README и дисклеймер советуют для данных
  реальной фирмы запуск у себя.
- Локальный `streamlit run` (без Docker) по-прежнему спрашивает внешний IP
  для строки «External URL»: `config.toml` не меняется, чтобы не рисковать
  поведением на Cloud.
- Если Cloud сменит базовый образ или способ установки, проверку «как на
  Cloud» нужно повторить; `deploy_smoke` для этого и есть.
- Тест `test_phase4_file_loads_unchanged` сравнивает повторную выгрузку файла
  фазы 4 с учётом версии: файл выгружен версией 1.0.0.dev0.
